# globalimport-web
Este proyecto trata de desarrollar un sitio web de comercio electrònico a la empresa ficticia "GlobalImport S.A". El proyecto tiene como finalidad poder integrar el uso de HTML y JavaScript aplicando buenas pràcticas de desarrollo y control de versiones desde el inicio del proyecto.
El proyecto se construirà de manera incremental con requerimientos especìficos los cuales se deben versionar en GitHub mediante commits claramente identificados.
